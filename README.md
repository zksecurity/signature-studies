# Signatures Formalized

The built website for [signature-security-lean](https://github.com/zksecurity/signature-security-lean), a Lean formalization of BLS, OOPS, and Proximity Signatures security, and [agm-lean](https://github.com/zksecurity/agm-lean).

Live at https://zksecurity.github.io/signatures-formalized/. This repository holds generated static files only; discuss the formalization in the [signature-security-lean Discussions](https://github.com/zksecurity/signature-security-lean/discussions).
